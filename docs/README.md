# Documentation

This directory holds long-lived product, architecture, and security documentation that explains why the Platform is built and operated as it is.

## Contents

- `PRODUCT_AND_SYSTEM_ARCHITECTURE.md` — Overall product and technical architecture.
- `product/delivery/DELIVERY_TRACKER.md` — Master delivery status and links to living phase task documents.
- `adr/` — Architecture Decision Records.
- `product/` — User journeys, policies, and feature requirements.
- `security/` — Threat models, data maps, and security standards.

Documentation that changes system behavior is reviewed with the implementation and kept free of secrets and production PII.
