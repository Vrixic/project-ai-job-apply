# Product Documentation

Contains candidate journeys, functional requirements, user-facing policies, metrics, rollout plans, and acceptance criteria.

## Planned subfolders

- `delivery/` — Master delivery tracker and living task documents for roadmap phases.
- `journeys/` — Onboarding, discovery, application, outreach, notification, and billing flows.
- `requirements/` — Feature requirements and acceptance criteria.
- `policies/` — Automation, review, contribution, freshness, and fair-use behavior.
- `metrics/` — North-star, funnel, guardrail, and experiment definitions.
- `research/` — Properly sourced market and user research summaries.
- `rollouts/` — Feature readiness and staged-release plans.

Product documents define outcomes and constraints without duplicating implementation details owned by ADRs.

## Foundation evidence

The [Phase 0 product foundation](foundation/README.md) records the approved US tech-professional
launch focus, research protocol, legal register, naming gate, ATS fixture policy, and quality
