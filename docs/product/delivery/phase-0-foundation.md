## Objective

Establish the reviewed product boundaries, canonical data/contracts, legal and privacy posture, security model, engineering foundation, and quality baselines required for every later delivery.

## Deployment posture

Use the lean-until-demand profile in `us-east-2`: one gateway, one worker, API Gateway/Cloud Map
ingress, Single-AZ PostgreSQL with backups/PITR, no Redis, and no ALB. Prove one shared development
environment first; keep isolated staging ready as code and provision it on demand for release,
restore, migration, security, and launch acceptance.
