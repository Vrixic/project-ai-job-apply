## Implemented boundary

Trusted original task/allocation/work -> frozen native work/completion ports -> fixed signed
numeric Documents control Lambdas -> existing owning work/completion stores. The dedicated
content process receives only four work methods and one completion method. No issue/renew,
other-document selection, background-terminal settlement, native launch/stop, SQL, object,
provider/model creation, renderer or retirement/purge capability is added. Normal Documents root
exports and existing private RPC schemas/handlers remain unchanged; a private subpath supplies
the new factory. Existing source and SQL authority remain the owners of these transitions.

The factory detaches exact allocation/task/owner/application/generation/work and consent
metadata. Targets must be distinct functions in the original account/us-east-2 with numeric
versions. Claim accepts only the original document/hash/consent date and only one transport
attempt. A returned work ID differing from the original refuses even with matching hash/document.
One acknowledged claim permits exactly one mutually exclusive original settlement attempt.
Only acknowledged normal fulfillment settlement permits a single version-one original completion;
rejected/undispatched closure cannot. Completion pins owner/application/generation and the exact
unaltered reference/time/hash reply. Expired/future completion or retargeting refuses before
Invoke. Lost/contradictory claim, settlement or completion acknowledgements remain unresolved;
no in-process retry or new authority follows. Across-host one-time authority still belongs to SQL.
Already-completed acknowledgement cannot restore content; the original actor requires claimed.

The production path constructs the normal Lambda SDK lazily after gates, fixed endpoint/region,
one SDK attempt and silent logger, without endpoint-environment override or test credentials.
Test injection refuses outside NODE_ENV=test. One active transport is retained until the original
send settles, including an ignored abort. Timeout requests cooperative abort and withholds late
reply; it is deliberately not a hard local Promise.race deadline or remote quiescence certificate.
The kernel deadline bounds the dedicated host, not remote work. Flags default off and withdrawal
withholds acknowledgement. Positive provider result semantics remain the original actor's duty.

Trusted allocation equality is not authentication or an owning task-admission check. Reviewed
sender/receiver IAM and per-task/private admission, original version/configuration retention,
managed task/image/entrypoint and owner evidence/provider bootstrap remain release work. No
public route, new control deployment, role permission or activation is created by this factory.
