## Implemented boundary

Trusted scalar producer -> Applications immutable packet -> exact current memory-reference owner
check -> owning approval/start/dispatch SQL transaction. At most one reference per generated kind;
owner/application/hash and original identity/time are closed and bound into the packet hash.
Public API/export projections carry seven scalar keys, omitting internal reference ownership.
No public request accepts reference authority or generated document content.

Approval uses the earliest original deadline; approval/start/manual start/dispatch recheck time.
Missing memory/different generation refuses new authority; owner outage/missing capability is
unavailable. Bound packet admission never invokes legacy re-tailoring or saved-draft recovery.
An owner read crossing expiry refuses after returning. Ordinary edits carry the original deadline,
refuse hash replacement without reference and prevent same-generation renewal/version rollback.
Descendants can keep the original deadline but native edit-authority issuance is still required.
Preparation completion carries scalar authority through the activity into the new reviewed packet;
expired or foreign material cannot become an approved generated artifact.

Applications 0008 adds one metadata-only column and three admission/edit triggers on existing
relations, validates shape, ownership/hash, completion + 1,800,000 ms and creation window, and
extends the closed invalidation reasons. Native admission independently uses the database clock.
Late settlement/confirmation/ambiguous-state retention never grants new dispatch or deletes evidence.
No generated content, renderer output, model/object access, new relation or old-row timestamp backfill.
