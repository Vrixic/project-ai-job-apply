# Security and Privacy Documentation

Contains the security architecture and evidence required to protect candidate identity, career history, connected accounts, and application actions.

## Planned subfolders

- `threat-models/` — Extension, remote browser, uploads, AI, OAuth, and service threats.
- `data-maps/` — Classification, flows, subprocessors, retention, and deletion.
- `standards/` — Authentication, encryption, logging, secrets, and secure coding.
- `reviews/` — Design/release security review records.
- `privacy/` — Consent, rights, export, deletion, and minimization specifications.
- `incidents/` — Sanitized post-incident reviews and follow-up actions.

This directory contains policy and sanitized evidence, never live secrets, tokens, or raw user data.
