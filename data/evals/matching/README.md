# D1 Matching Evaluations

`d1-match-assessment.v1.json` is a generated-synthetic, versioned acceptance candidate for the
conservative D1 match-assessment kernel. Six synthetic fixtures cover software, data, and product
roles at declared early and mid career-stage strata. Career stage is evaluation metadata only: the
kernel does not receive or infer it.

The 24 core cases give each of the six segment cells the same four scenarios: exact comparable
alignment, a work-mode-only conflict, an employment-type-only conflict, and sparse or
semantic-near evidence. Twelve cross-cutting guardrails cover absent and unknown typed fields,
normalization, semantic-near non-overlap, compensation non-comparability, a dual conflict, and both
values of the legacy sponsorship field.

This set claims product-scenario coverage only. It does not claim statistical prevalence,
demographic representativeness, provider representativeness, real-candidate behavior, ranking or
calibration quality, eligibility, application outcomes, or production acceptance. Changing an
approved input, expected result, taxonomy, or threshold requires a new set version and renewed
Product and QA review.

The release rubric is [`d1-match-assessment.v1.md`](../rubrics/d1-match-assessment.v1.md).
