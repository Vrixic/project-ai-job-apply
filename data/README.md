# Versioned Data Assets

This directory contains reviewed datasets that are part of product behavior and should change through code review.

## Subfolders

- `taxonomies/` — Skills, titles, seniority, industry, and location mappings.
- `evals/` — Matching, extraction, generation, and safety evaluation sets.
- `seeds/` — Synthetic development/demo data.

Large runtime datasets and user data belong in managed storage, not the repository.
