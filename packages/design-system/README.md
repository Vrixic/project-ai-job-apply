# Design System

Holds shared visual tokens, accessibility foundations, and reusable web/mobile primitives that keep the experience coherent without forcing identical platform layouts.

## Planned subfolders

- `tokens/` — Color, typography, spacing, motion, elevation, and themes.
- `web/` — Accessible React web primitives.
- `mobile/` — React Native primitives.
- `icons/` — Product-owned icon set.
- `patterns/` — Forms, review-by-exception, status, and error patterns.
- `docs/` — Usage guidance and accessibility behavior.
- `tests/` — Accessibility, interaction, and visual regression tests.

Feature-specific composed components remain in their owning frontend application.
