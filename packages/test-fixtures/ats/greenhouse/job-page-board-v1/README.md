# Greenhouse job-page board v1

This inert fixture represents only the accepted `greenhouse-board-v1` public job-page detector
surface. It preserves the title heading, location, description-region, missing company marker,
and missing JobPosting JSON-LD behavior observed in the authorized public example.

All employer, job, URL, person, and regional values were replaced with reserved examples. The
application form was omitted because D2 reads public job fields only; form behavior belongs to D3.
The raw response was never written to the repository and was destroyed at the end of the bounded
inspection process.

The accepted package passed Gitleaks `8.30.1`, Presidio Analyzer `2.2.364`, the repository fixture
validator, human sanitization review, and a separate representativeness review on 2026-09-03.
This fixture does not authorize application submission, another provider or variant, store
distribution, or unrestricted ingestion.
