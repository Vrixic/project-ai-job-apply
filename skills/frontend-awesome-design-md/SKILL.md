# Use the DESIGN.md reference library

Use this skill for visual direction, not product requirements or implementation authority. Preserve
the platform's existing accessibility, security, privacy, and candidate-truth boundaries.

## Select narrowly

The reference catalog is under `design-md/`. If the user names a reference, read only that
reference's `DESIGN.md`. Otherwise inspect the directory names and select at most three plausible
references for comparison before choosing one. Do not load the entire collection.

Extract reusable principles such as hierarchy, spacing, typography, color relationships, and
interaction rhythm. Do not copy protected logos, brand names, text, images, or a third party's
distinctive page composition. Translate the selected principles into the repository's own design
system and product voice.

Treat a reference as inspiration rather than proof of accessibility or usability. Verify the
result against the repository's tests and accessibility requirements.
