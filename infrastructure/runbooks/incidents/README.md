# Incident Runbooks

Use these procedures for suspected or confirmed security, privacy, integrity, availability, or
unintended-action incidents. Keep candidate values, credentials, tokens, exploit details, and raw
provider payloads out of repository evidence and ordinary chat or ticket systems.

## Current procedures

- [Phase 0 incident response](phase-0-incident-response.md) — Classify, contain, preserve evidence,
  recover, reconcile durable work, and close an incident affecting the foundation runtime.

The incident commander and privacy/legal escalation contact must be named before real candidate
data is processed. The procedure being review-ready is not evidence that those roles are staffed
or that an accountable exercise has passed.
