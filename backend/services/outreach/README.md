# Outreach Service

Owns permitted contact context, personalized drafts, user approval, send state, duplicate prevention, restrained follow-up scheduling, and suppression.

## Planned subfolders

- `contacts/` — User-supplied or lawfully licensed contact records.
- `drafts/` — Grounded email/message generation and versioning.
- `approvals/` — Recipient, content, account, and schedule authorization.
- `sending/` — Send commands and provider-independent state.
- `followups/` — Limited follow-up policies and reminders.
- `compliance/` — Rate limits, suppression, bounce, and complaint rules.
- `tests/` — Truthfulness, authorization, dedupe, and abuse tests.

This is candidate-directed personal outreach, not a bulk marketing or scraping system.
